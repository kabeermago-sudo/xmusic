🎮 Controller Guide
Mode Switch: Start Button (toggles Drum/Chord mode)
Drum Mode: L1 = Kick, R1 = Snare
Chord Mode:
• D-Pad & Face Buttons = Root Notes
• L1 = Major 7, R1 = Minor 7
• L2 = Suspended, R2 = Diminished
• Right Stick = Pitch Bend
Recording: Back/Select Button (toggles loop recording)
