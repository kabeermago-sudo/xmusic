🎮 Gamepad Instrument Studio

Connect an Xbox controller and press any button to start.
Mode: Drum Kit
Press buttons to play instruments!

🎯 Quick Start:

1. Connect Xbox controller
2. Click "Start Audio"
3. Press controller buttons to play
4. Use START button to switch modes

🎮 Controller Layout

🥁 Drum Mode

LB Kick Drum
RB Snare
A Hi-Hat
B Crash

🎹 Chord Mode

D-Pad ↓ C (I)
D-Pad ← D (ii)
D-Pad ↑ E (iii)
D-Pad → F (IV)
A G (V)
B A (vi)

🎛️ Modifiers

LB Major 7
RB Minor 7
LT Suspended
RT Diminished
START Switch Mode
BACK Record/Stop

🎵 Pro Tips:

Chord Mode: Hold modifier buttons (LB/RB/LT/RT) while pressing chord buttons for different qualities
Recording: Press BACK to start/stop loop recording
Pitch Bend: Use right analog stick for pitch modulation
